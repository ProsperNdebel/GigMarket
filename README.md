# GigMarket
Connecting Gig seekers with Gig providers

## Features

- **Math Utilities**: Common mathematical operations for business calculations
  - Basic arithmetic (add, subtract, multiply, divide)
  - Power operations
  - Percentage calculations
  - Statistical functions (average)

## Project Structure

```
GigMarket/
├── src/
│   └── utils/
│       ├── math_utils.py    # Mathematical utility functions
│       └── README.md         # Utils documentation
├── tests/
│   └── test_math_utils.py   # Unit tests for math utilities
├── requirements.txt          # Project dependencies
└── README.md                 # This file
```

## Installation

```bash
pip install -r requirements.txt
```

## Running Tests

```bash
pytest tests/ -v
```

## Development

This project follows Test-Driven Development (TDD) practices. All features include comprehensive unit tests with edge case coverage.

For more details on specific utilities, see the documentation in each module's directory.
